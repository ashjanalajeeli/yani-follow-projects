# إعداد الاشتراكات اليدوية

1. راجع طلب الدمج وادمجه في `main` بعد التأكد من الاختبارات.
2. طبّق ترحيل `20261022120000_manual_subscriptions.sql` على مشروع Supabase. لا تُطبّق الترحيل على الإنتاج قبل مراجعة سياسات RLS والتخزين.
3. من Supabase Dashboard افتح **Authentication → Users** وانسخ UUID لحساب المالك. افتح `bootstrap-first-admin.sql` في SQL Editor، واستبدل UUID المثال بمعرّف الحساب الصحيح، ثم نفّذ الاستعلام مرة واحدة. لا تمنح دور admin إلا لحساب موثوق.
4. سجّل الدخول إلى التطبيق بحساب المشرف وافتح `/admin`. أدخل اسم المستفيد ورقم الحساب/المحفظة والعملة والتعليمات الدقيقة لكل وسيلة، ثم فعّل الوسائل التي أصبحت جاهزة فقط. الوسائل الافتراضية تبدأ غير مفعّلة.
5. بعد إعداد طرق الدفع، اختبر طلبًا بقيمة صغيرة في بيئة اختبار/حساب مناسب، وتأكد من أن الإيصال خاص، وأن المستخدم العادي لا يستطيع رؤية طلبات الآخرين أو تفعيل خطته.

لا يستخدم هذا التدفق بوابة دفع مباشرة. يرفع المستخدم صورة أو PDF إلى حاوية خاصة؛ يراجع المشرف الإيصال ومطابقة التحويل خارج النظام ثم يوافق أو يرفض من لوحة الإدارة. رفع الإيصال لا يثبت وصول المال ولا يفعّل الاشتراك تلقائيًا. الأسعار بالدولار كما أُدخلت في قاعدة البيانات، والضريبة المحتملة غير مشمولة وتُراجع يدويًا.
